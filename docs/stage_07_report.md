## 冻结口径

这些常数写在验证集开跑之前，结果出来之后没有再调。

| 项目 | 取值 |
| --- | --- |
| 训练 | 2024-11-01 至 2025-10-31 |
| 温度拟合窗 | 2025-11-01 至 2026-01-30 |
| 打分窗 | 2026-02-01 至 2026-04-30 |
| RSI | Wilder RSI(6)，只在闭合的 5 分钟线上更新 |
| 回踩 | 信号前 6 根内曾低于 40，上一根 ≤ 50 且当根重新上穿 50 |
| 结构 | 回踩前另取 6 根作基准；回踩均量必须低于这 6 根；回踩到信号的每根收盘都在当根 VWAP 之上，最低价不跌破基准最低价 |
| 趋势 | 收盘高于 VWAP，VWAP 斜率 > 0，偏离不超过 1·ATR；市场状态必须是 `TREND_UP` |
| 冷却 | 同一标的 6 根内不重复发信号；重叠样本权重为 0 |
| 止损 / 止盈 | 1·ATR；止盈距离是止损距离的 1.5 倍 |
| 持仓 / 挂单 | 最长 90 分钟，且不超过 15:55 ET（半日市 12:55）；限价单 10 分钟 |
| 穿透 | 0.02 美元。本阶段没有加载 1 分钟线，同一根同时碰到止盈和止损时按止损计 |
| 成本 | 半价差 0.01 美元，佣金 0.05% |
| 拟合下限 | 训练路径标签至少 30 条才允许拟合；温度窗至少 20 条才允许选温度 |
| 先验方差 | 特征 1，板块偏移 0.25，波动率偏移 0.25 |
| 温度网格 | 0.50 到 2.00，步长 0.05。打平则取更靠近 1 的值 |
| 门禁 | 校准后的期望净 bps 必须严格大于 0 |

RTH VWAP 在纽约日期切换时把分子和分母清零。当天第一根必须从 09:30 ET 开始，否则该时段 VWAP 不发布。Wilder RSI(6) 不随日期清零：平均涨幅和平均跌幅跨常规时段保留，只在被接受的闭合 K 线上更新，种子是前 6 次收盘价变化。盘中回调缓冲是另一套状态，每个交易日重开，而且要等 VWAP、RSI、ATR(14) 和 VWAP 斜率同时存在才开始积累。斜率用最近 4 个 VWAP（滞后 3 根）。缓冲还要再满 12 根（6 根基准加 6 根回踩），所以完整时段里最早的信号大约落在开盘后第 17 根。

回踩均量只统计探底那根到信号前一根，不含确认那根。这样确认放量不会把已经缩量的洗盘判掉。

期望净 bps 按

`p_TP · R_TP − p_SL · R_SL + p_TO · E[R_TO] − Cost`

计算。`R_TP` 和 `R_SL` 是下单时已经量化到分的止盈、止损距离。`E[R_TO]` 只用训练集里超时出场的毛 bps 均值。往返成本按进场价计算：双边佣金 10 bps，再加上 `0.02 / 价格` 换算的价差 bps。规则意图上的概率仍是未校准单纯形 0.333333334 / 0.333333333 / 0.333333333，不参与是否发单。

层级模型是三分类逻辑回归的 MAP，参考类是超时。板块哑变量去掉排序后的最后一只父行业（XLY），波动率三分位去掉最高一档。这是高斯先验下的后验众数，不是 MCMC 后验样本。温度只允许用 2025-11-01 至 2026-01-30 的标签估计，打分窗的标签不进入任何系数。

规则回放约 7.2 秒。31 个意图里 30 个被风控拒绝：摩擦 28，整数股超出风险或仓位上限 2。成交 1 笔。概率门禁发出 0 个意图，结束现金仍是 1,600 USDC。

这一笔不是同柱歧义。

推荐规则在看结果之前写死：概率门禁只有在打分窗成交至少 30 笔、平均净 bps 比规则高出 2 倍合并标准误、盈利因子不差、最大回撤不超过规则的 1.2 倍时才入选。门禁成交是 0，规则成交是 1。结果文件里的 `recommended` 是 `rule`。这一笔 −57.90 bps 不能支撑上线，也不作为放宽 RSI、缩短结构窗或降低 30 条拟合下限的理由。

摩擦拒绝占了 28/31。1·ATR 止损配 1.5 倍止盈时，单股毛利经常盖不住双边 0.05% 佣金和 0.02 美元价差，宪法里的 20% 摩擦上限会把单子挡下。这是执行层的结果，不是事后把止盈改宽的理由。

## 因果与单纯形

改写后一根不改变已经形成的回调形态，也不改变已经算完的 RSI。后一天的 VWAP 只含当天成交量；测试里第二天第一根的 VWAP 等于该根价格，不混入前一天的量。未闭合的 K 线会被拒绝。

`softmax` 和温度缩放之后，三类概率之和在测试里等于 1。可分的合成样本上，拟合后的 MAP 会把概率质量放到正确的一类。权重为 0 的重叠样本不改变系数。2026-02-01 之后的日期进不了训练拟合，也进不了温度拟合。锁箱日期 2026-05-01 在读盘之前被拒绝。

这些测试锁住了单纯形和无泄漏。它们替代不了打分窗上的可靠性曲线。打分窗没有拟合后的概率，ECE、Brier 和 Bootstrap 区间都是空的。`ece_improved` 为 false。
