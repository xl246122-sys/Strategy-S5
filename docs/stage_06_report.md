## 冻结口径

这些常数写在验证集开跑之前，结果出来之后没有再调。

| 项目 | 取值 |
| --- | --- |
| 训练 / 验证 | 2024-11-01 至 2025-10-31 / 2025-11-01 至 2026-04-30 |
| 窗口与最短更新 | 78 根，约一个常规时段 |
| 相对强弱 | 板块正交残差的最近 6 根之和 |
| 入场 | α > 0 且 z > 2，严格大于 |
| RLS | λ = 0.98，先验协方差 100·I，系数方差再乘残差 EWMA |
| Kalman | 状态噪声 0.0001·I，观测噪声 1，初值协方差 I，Joseph 更新 |
| 止损 / 止盈 | 1·ATR；止盈距离是止损距离的 1.5 倍 |
| VWAP | 收盘高于当日 VWAP，且偏离不超过 1·ATR |
| 持仓 / 挂单 | 最长 90 分钟；限价单 10 分钟 |
| 成本 | 半价差 0.01 美元，佣金 0.05% |
| 状态 | 只有阶段 5 的 `TREND_UP` 允许 S1。`UNKNOWN` 与 `HIGH_VOL_PANIC` 禁止新开多仓 |

归一化收益来自阶段 5 的因果特征簿：同一时钟过去最多 20 个交易日的样本标准差，当天不进入。缺归一化收益的根直接跳过，不补 0。三套滤波都要满 78 次更新才开口。

板块对 SPY 的 γ 是过原点的滚动回归，窗口含当前根、不含截距。同一个时点重复推送不改变残差。残差按父行业每根算一次，不随子 ETF 重估。窗口内残差与 SPY 的点积在测试里低于 1e-9。全样本把各根的 SPY 与残差堆在一起的余弦是 0.00049293：γ 随时间变化，所以跨窗口的合并余弦不是 0。窗口内的点积才是正交性的证据。

状态方程是

r̃_stock = α + β_m r̃_SPY + β_sec r̃_sector_perp + ε。

Kalman 只有 predict 与 update，代码里没有平滑函数。RLS 的 λ 锁在 0.96 到 0.99。滚动 OLS 解正规方程；奇异时记为未解出。无噪声直线仍能给出系数，但残差方差为空，z 没有定义，不会发信号。

意图上的三分类概率是未校准单纯形 0.333333334 / 0.333333333 / 0.333333333，版本号带 `uncalibrated`。它不参与入场。期望净 bps 同样不参与入场。校准留给阶段 7。

限价按收盘价四舍五入到分。止损和止盈向下取整到分。股数由回测引擎按整数股、风险预算和单仓上限决定。

## 撮合修正

阶段 4 的引擎当时只跑单标的，止损、超时和 15:55 强平用了当前这根 K 线，没有核对标的。多标的回放时，别的标的的低点会把持仓打掉。本阶段改成：止损、止盈、超时和强平只看该持仓自己的 K 线。15:55 撤未成交单仍按时钟，先走到 15:55 的标的会撤掉全部挂单，避免收盘后成交。窗口极值改成按标的索引，数值与逐根扫描相同。回归测试在 SMH 出场那一根旁边放了一根 GDXJ、最低价 1 美元，SMH 仍按自己的止盈价 101.50 成交。

同一条 z > 2，三套模型的信号数是 1、3、82。Kalman 与 RLS 的后验方差在这条门槛下几乎过不去。这三套 z 不在同一把尺子上。看到这个差距之后没有把它们调成一样。

Kalman 那 1 个信号被摩擦否决。RLS 的 3 个里，2 个因整数股超出风险或仓位上限，1 个因摩擦。OLS 的 82 个里，79 个被风控拒绝：摩擦 68、整数股 10、已有持仓 1。训练集成交是 0。三套回放各约 7 秒。Kalman 与 RLS 结束现金 1,600 USDC。OLS 结束现金 1,601.333840 USDC。都没有锁仓。

三笔都不是同柱歧义。

推荐规则在看验证集之前写死，并由测试锁住。Kalman 只有在同时满足这些条件时才入选：成交至少 30 笔，平均净 bps 比 RLS 与 OLS 里较强的那个高出 2 倍合并标准误，盈利因子不差，最大回撤不超过对方的 1.2 倍。否则若 RLS 以同样标准胜过 OLS，选 RLS。其余情况名字记为 `ols`。这个名字的意思是保留更简单的滚动回归。Kalman 与 RLS 的验证成交是 0，OLS 是 3，都没有达到 30 笔。结果文件里的 `recommended_model` 是 `ols`。

22.15 bps 的均值小于 38.78 bps 的标准误。这 3 笔不能支撑上线，也不作为放宽 z、改 Q、改 λ 或放宽止损的理由。

## 因果测试

改写 t+1 的个股或板块收益，三套模型在 t 的 α 不变，最后一根的 α 会变。同一时钟上，开盘附近的历史波动更大，所以同样约 1% 的原始收益，09:30 槽的归一化冲击小于 12:00 槽。改写下一天不改变当天的归一化收益。z 恰好等于 2 被拒绝。`UNKNOWN` 与 `HIGH_VOL_PANIC` 被拒绝。包内没有浮点字面量，也没有平滑函数。
