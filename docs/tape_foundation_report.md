## 交易成本

封存路径里的三个数没有分叉：

- 佣金率 `0.0005`，买卖各按成交名义金额乘一次
- 半价差 `0.01` 美元/股，买卖各扣一次
- 保守穿透 `0.02` 美元，买单要 `Low <= 限价 - 0.02` 才成交

报价替代是收盘价两侧各 `0.01`，价格笼子 `0.80` 到 `1.20`。历史盘口不存在，这是事先声明的替代。

例：买入价 100、止盈 101、10 股。进场佣金 0.50，出场佣金 0.505，双边半价差 0.20，合计 1.205 美元。金额用 `Decimal`。
