## 冻结口径

这些常数写在本阶段测试之前，没有用成交样本回改。

| 项目 | 取值 |
| --- | --- |
| 一次调用 | 一个截面。同一标的在这次调用里最多交出一个意图 |
| 去重键 | `(symbol, bar_close_time)`，再加同标的冷却 |
| 冷却 | 默认 30 分钟，即 6 根 5 分钟线。构造时可以改。窗口含终点：距离上次成交锚点小于等于 30 分钟都记 `COOLDOWN_DUPLICATE` |
| 冷却锚点 | 只有真正分到槽位的意图才写入。没分到槽的标的，下一根可以再竞争 |
| 风险单位 | `(限价 − 止损) / 限价 × 10000`，单位是 bps。限价用 `entry_price_ceiling` |
| 排序 | 风险调整净期望 `E[net_bps] / 风险单位` 高者优先；相同则预测区间下界高者优先；再比更窄的半价差、更小的名义金额、策略名、意图编号 |
| 合成 | 保留唯一胜出意图。不把两个策略的价格或概率平均成一笔新单 |
| 槽位 | `available_slots = 5 − 持仓数 − 在途买单数` |
| 板块 | 用阶段 6 的父板块映射。同一父板块连同已有持仓和在途，最多 2 个。名额用完后，即使还有空槽，也不再加这一板块 |
| 点差 | 报价半价差只在期望打平时参与排序。摩擦门禁用的是写死的 0.01 美元，不用这份报价 |
| 摩擦 | 双边佣金 0.05%，加两边各 0.01 美元。占目标止盈毛利 `> 20%`，或 `E[net_bps] ≤ 0`，记 `NEGATIVE_OR_INSUFFICIENT_NET_EDGE` |
| 陈旧 | 沿用周期 K 线门，`data_freshness_ms > 360000` 记 `DATA_STALE` |
| 时间 | 15:45 ET（半日市 12:45 ET）起记 `PAST_ENTRY_CUTOFF_TIME`。09:30 之前和周末记 `NON_RTH`。与宪法里的开仓窗口同一边界 |
| S4 | `production_mode=True` 时记 `STRATEGY_LIVE_DISABLED`。代码常量若偏离 false，研究模式也会拒绝 |
| 状态 | 只拦 `UNKNOWN` 和 `HIGH_VOL_PANIC`。`TREND_DOWN` 不在仲裁器里再拦一次，各策略自己的门禁仍然有效 |

## 同标的

SMH 在 15:00 ET 同时出现三笔。S1 的净期望是 33 bps，止损距离 200 bps，风险调整期望 0.165。S3 的净期望是 50 bps，止损距离 1000 bps，风险调整期望 0.050。S1 留下，S3 记 `SAME_BAR_OUTRANKED`。S4 在这批样例的生产模式下先被拒绝，不参加比较。

期望相同的时候，区间下界更高的留下；下界也相同，半价差更窄的留下；再往后是名义金额更小、策略名、意图编号。半价差更窄不能压过更高的风险调整期望。测试把输入顺序颠倒，胜出名单和原因码顺序不变。

一次调用里如果同一标的还有更晚的一根，而且已经落在冷却窗外，仍然只留较早的那一笔，晚的记 `SAME_SYMBOL_SUPERSEDED`。要让下一根重新竞争，需要下一次调用，并且这本书里该标的已经不在持仓或在途里，冷却也已经过去。

## 槽位和板块

空账本的样例排名是 SOXX 0.200、IGV 0.190、HACK 0.180、XOP 0.170、SMH 0.165、XBI 0.160、KRE 0.150、ITA 0.140。SOXX 和 IGV 占满 XLK 的 2 个名额。HACK 和已经赢过 S3 的 SMH 记 `SECTOR_CONCENTRATION`。XOP、XBI、KRE 补满 5 个槽。ITA 记 `OUTRANKED_FOR_SLOT`，明细是 `filled=5;available=5`。

5 个在途买单把可用槽打到 0 时，新标的记 `NO_AVAILABLE_SLOT`。标的自己已经在持仓或在途里，记 `SYMBOL_ALREADY_RESERVED`，即使别处还有空槽。没分到槽的标的不写冷却锚点，下一根可以再进。

## 拒绝码

一笔信号只记最先命中的原因。顺序是：行情陈旧、VWAP 缺口、不可交易或停牌、`UNKNOWN` / `HIGH_VOL_PANIC`、开仓时间、策略不在 S1–S4、S4 生产锁、板块不在映射里或父板块填错、已占槽、净期望或摩擦。样例日志里能直接看到 `DATA_STALE`、`VWAP_GAP_UNRECOVERED`、`SYMBOL_NOT_TRADABLE`、`STRATEGY_LIVE_DISABLED`、`NEGATIVE_OR_INSUFFICIENT_NET_EDGE`。测试另外锁住了 `MARKET_REGIME_BLOCKED`、`PAST_ENTRY_CUTOFF_TIME`、`NON_RTH`、`SECTOR_UNKNOWN`、`SECTOR_MISSTATED` 和意图上原有的拒绝原因。

审计行是 JSONL，字段只有字符串：`event`、`reason_code`、`symbol`、`strategy_id`、`intent_id`、`bar_close_time`、`detail`。新进程打开同一份日志时，会从 `ALLOCATE` 行恢复冷却锚点。样例的最后一行就是这样挡住了 10 分钟后的 SOXX。
